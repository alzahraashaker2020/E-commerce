# باقات اشتراك التجار — 26 أكتوبر 2026

إدارة الباقات في `/platform/plans` لمدير المنصة، وقراءة اشتراك المتجر في `/merchant/subscription` للتاجر. الباقات مستقلة عن عملات وأسعار منتجات المتجر. لا توجد بوابة دفع أو خصم تلقائي أو فاتورة ضريبية في هذه الدفعة؛ التفعيل والتجديد بإجراء إداري يدوي يسجل مرجعًا اختياريًا وسجل تاريخ.

## الباقات

يمكن إنشاء وتعديل الاسم والسعر والعملة ومدة الفترة بالشهور من 1 إلى 36، ومدة تجربة من 0 إلى 90 يومًا، وحد عدد المنتجات أو تركه غير محدود، وإتاحة الباقة أو تعطيلها. السعر محفوظ كعدد صحيح من أجزاء العملة (100 جزء للوحدة)؛ العملات المدعومة حاليًا EGP وUSD وEUR وGBP وSAR وAED. الاشتراك لا يحول العملات ولا يغير أسعار المنتجات.

لأن المستخدم لم يحدد أسعارًا، أضيفت Starter وGrowth وPro كمسودات **غير مفعلة** وأسعارها صفر لحين تحديدها. حدود المسودات المقترحة 100 و1000 وغير محدود، وتجربة 14 يومًا، وكلها قابلة للتعديل. لا تعتبر أسعارًا تجارية معتمدة أو باقات مجانية منشورة. سعر صفر مسموح عمدًا لإنشاء باقة مجانية إذا فعلها مدير المنصة صراحةً.

## الاشتراكات

- Assign يطبق باقة متاحة فورًا، ويحفظ نسخة من اسمها وسعرها وعملتها وفترتها وحد المنتجات، ويبدأ فترة جديدة من الآن. لا يعدل منتجات المتجر ولا ينفذ تحويل سعر أو تسوية مالية بين باقتين.
- Trial متاح مرة واحدة قبل أول اشتراك ولخطة تسمح بتجربة. يمنع تكراره أو إعادة استخدامه بعد إلغاء أو انتهاء التجربة.
- Renew يتطلب نفس الباقة الحالية وأن تكون متاحة، ويطبق شروط الباقة الحالية صراحةً. يضيف فترة إلى تاريخ انتهاء الاشتراك المدفوع الذي لم ينته، ويبدأ من الآن إذا انتهى أو ألغي أو كان تجربة. تغيير الباقة يتم بـAssign.
- Cancel يلغي البيع والتعديلات فورًا، دون حذف بيانات أو رد مبالغ تلقائيًا. التعليق الإداري للمتجر مستقل، وتجديد اشتراكه لا يلغي حالة Suspended.
- تستخدم إصدارات Version لمنع تجديد نفس النسخة مرتين أو الكتابة فوق تعديل متزامن. سجل SubscriptionEvents يحفظ العملية والفاعل والمرجع وشروط السعر والفترة، وليس إثبات تحصيل مالي.
- تعديل باقة أو تعطيلها لا يغير الاشتراكات القائمة بأثر رجعي. الباقة المعطلة لا تقبل تفعيلًا أو تجديدًا جديدًا، وتظل شروط الفترات القائمة محفوظة.

المتاجر السابقة للميزة تظل Legacy وتستمر دون فرض سعر أو موعد انتهاء حتى يربطها مدير المنصة بباقة. المتاجر الجديدة تبدأ Pending للاشتراك؛ يمكن الدخول والقراءة لكن لا يمكن إدارة المتجر أو استقبال طلب جديد حتى التفعيل أو التجربة. لا يوجد تفعيل تلقائي لباقة افتراضية.

## التطبيق الفعلي للحدود

يفحص الخادم تاريخ الانتهاء UTC عند كل طلب، دون الاعتماد على وظيفة مجدولة أو حالة الواجهة. المنتهي أو الملغي أو غير المفعل لا يقبل POST checkout أو تغييرات إدارة التاجر، مع السماح بالدخول وقراءة الاشتراك والمنتجات والطلبات السابقة. إيقاف المتجر الإداري يستمر بمنع كل طلباته وفق السياسة السابقة.

حد المنتجات يشمل كل المنتجات، حتى غير النشطة، ولا يشمل عدد المتغيرات. يطبق عند إنشاء منتج داخل معاملة Serializable مع العد والحفظ في قاعدة المتجر نفسها؛ لا تعتمد الحماية على عداد متصفح. الوصول للحد يرفض المنتج الإضافي، وتخفيض باقة تحت الاستخدام الحالي لا يحذف منتجات سابقة؛ يلزم حذف منتجات أو ترقية الباقة لإضافة منتجات أخرى. لا توجد حدود عدد طلبات أو تخزين أو موظفين مدعاة في هذه الدفعة.

## التخزين والترقية

Plans وSubscriptions وSubscriptionEvents داخل قاعدة المنصة SQLite المستقلة عن قواعد المتاجر. SubscriptionSchema يضيف الأعمدة والجداول ضمن معاملة دون حذف البيانات، وينشئ نسخة أصلية من قاعدة منصة قائمة قبل إضافة جداول الباقات، تحت backups/platform-before-subscriptions-*.db. التواريخ تعاد بصيغة UTC صريحة. لا تتغير قاعدة المتجر أو كميات المنتجات بسبب تخصيص باقة.

## التحقق

نجحت اختبارات التجارة الـ339، و220 فحصًا للعزل والاشتراكات على كل من SQLite وPostgreSQL، تشمل: مسودات غير مفعلة، رفض التفعيل من تاجر، صحة السعر والفترة، حفظ الشروط السابقة عند تعديل الباقة، تجربة مرة واحدة، رفض تجاوز حد المنتجات، رفض نسخة تجديد قديمة، التجديد من نهاية الفترة، الإلغاء، الانتهاء الحقيقي على قاعدة مؤقتة، الاستئناف وسجل العمليات. جربت السيناريوهات على SQLite وPostgreSQL مع متجرين مستقلين، وبناء API وAngular للإنتاج ناجح.

اختبار الانتهاء يعدل قاعدة منصة مؤقتة فقط عبر أداة الاختبارات؛ لا يوجد API عام لتزوير الساعة أو تاريخ الانتهاء.

ما زال لاحقًا: بوابة دفع موثقة وwebhooks، فواتير وتحصيل، تنبيهات قبل الانتهاء وفترة سماح، تسوية مالية لترقية/تخفيض منتصف الفترة، تجديد تلقائي، وحدود إضافية حسب الحاجة. لا تُرسل أي دفعات أو رسائل من هذه الميزة حاليًا.
